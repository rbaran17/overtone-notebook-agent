# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Read that document for the full standard and enforcement process.

In short, we expect everyone taking part in the project to:

- Be respectful and assume good intent in issues, reviews and discussions.
- Give and accept constructive feedback on code and ideas.
- Keep discussion focused on the work and avoid personal attacks.
- Avoid harassment, insults, and unwelcome sexual or discriminatory comments.
- Respect others' privacy, and do not publish their private information.
- Say when something is outside what the project can reasonably support.

If you have a concern about behaviour in the project, raise it privately with
the maintainers through GitHub rather than in a public issue or pull request.
